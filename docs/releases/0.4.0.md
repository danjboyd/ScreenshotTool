ScreenshotTool 0.4.0 adds Select Text: choose words in an image, copy just those words, or redact them. Text recognition stays on your computer.

## Upgrading

Use File ▸ Check for Updates, or download 0.4.0 when it is available.

## Changes

- **Select Text (all platforms):** choose Edit ▸ Select Text, or use the image's context menu, to see the words found in an image. Drag across words and lines, double-click a word, triple-click a line, or select all text. Copy copies the selected words as text; Redact Selected Text covers the selected lines in one undo action. Esc or a tool change leaves the mode. The shortcut is ⇧⌘E on macOS and Ctrl+Shift+E on Windows and Linux (#330, #351, #357, #362).
- **Redact Emails and Phone Numbers:** avoids adding a second redaction over text already covered, and says how many items were already redacted (#349). It briefly highlights newly covered items so you can see what changed (#364).
- **Result notices:** when a command briefly highlights new redactions, its result notice moves clear of the visible highlight where there is room. On macOS, the notice also reliably disappears after its fade (#372).
- **Text recognition on Windows:** reads large images in tiles to find text for Copy Text and Redact Emails and Phone Numbers (#368).
- **Window fit on Windows:** opening a large image keeps its window within the monitor's usable area, leaving the status bar clear of the taskbar (#374).
- **Text recognition on Linux:** Copy Text, Select Text and Redact Emails and Phone Numbers use `tesseract` when it is installed. If it is missing, the commands remain visible and explain how to install it (#367, #370).
- **Text labels:** a label's background fits the letters as drawn at the current zoom, including aligned and wrapped text (#369).

The macOS app is ad-hoc signed and not notarized, so Gatekeeper may ask before its first launch. See [Install ▸ macOS](https://github.com/danjboyd/ScreenshotTool#macos) in the README, or “Opening an unsigned app.txt” in the DMG.
