ScreenshotTool 0.3.6 is a patch release that fixes Redact Emails and Phone Numbers.

## Upgrading

Use Check for Updates, or wait for the automatic check.

## Changes

- **Redact Emails and Phone Numbers:** covers phone numbers that follow a date written with spaces, which 0.3.5 missed, and no longer leaves part of a number readable. When it can't tell where a date ends and a number begins, it covers both.

**Full Changelog**: https://github.com/danjboyd/ScreenshotTool/compare/v0.3.5...v0.3.6
