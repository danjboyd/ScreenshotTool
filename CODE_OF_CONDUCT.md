# Code of Conduct

## Our Standard

This project is a small, maintainer-run open source repository. Participation
in the project should stay respectful, constructive, and technically focused.

Examples of acceptable behavior include:

- giving and receiving technical feedback in good faith
- being respectful of differing experience levels and viewpoints
- keeping discussions relevant to the project
- assuming mistakes can be corrected without hostility

Examples of unacceptable behavior include:

- harassment, intimidation, or sustained hostility
- hate speech or discriminatory language
- personal attacks, insults, or trolling
- doxxing or sharing private information without permission
- spam, off-topic disruption, or deliberately wasting reviewer time

## Scope

This code of conduct applies to project spaces, including issues, pull
requests, discussions, and other interactions in this repository.

## Maintainer Responsibilities

The maintainer may remove, edit, or reject comments, commits, code, issues, and
other contributions that are not aligned with this code of conduct. The
maintainer may also temporarily or permanently restrict participation in the
project for unacceptable behavior.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer using
the contact information on the project owner's GitHub profile.
