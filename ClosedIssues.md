# Closed Issues

- Status bar hide left an empty strip where the bar used to sit. Resolved on 2025-11-20 by resizing the window content by the status bar height whenever the toggle flips, so hiding collapses the reserved space and showing expands it again before relayout. `resizeWindowToImageSize` now honors the current status bar height, and `StatusBarToggleProbe` guards the hide/show path so the scroll view can’t grow and leave a blank strip. _(Opened 2025-11-20 — Closed 2025-11-20)_
- Copying an annotated image dropped highlighter strokes from the clipboard output on GNUstep. Resolved on 2025-11-05 by keeping stroke rasterisation in the CPU path for GNUstep builds so highlighter overlays survive flattening. Guarded by `ClipboardHighlighterProbe`. _(Opened 2025-11-04 — Closed 2025-11-05)_
- Clipboard highlighter opacity stacked too aggressively in clipboard exports, obscuring underlying content. Resolved on 2025-11-05 by de-duplicating per-stroke raster stamps and guarding with `ClipboardHighlighterOpacityProbe` so repeated passes stay translucent. _(Opened 2025-11-05 — Closed 2025-11-05)_
- Toolbar badges stopped reflecting colour changes after the async refresh refactor. Resolved on 2025-11-05 by regenerating toolbar images from fresh base glyphs, caching items safely, and guarding the helper with `ToolbarBadgeRefreshProbe`. _(Opened 2025-11-03 — Closed 2025-11-05)_
- GNUstep native tooltips resurfaced after the refactor. Resolved on 2025-11-05 by restoring a custom tooltip controller, suppressing the native manager via persistent defaults, and guarding the behaviour with `TooltipsSuppressedProbe`, which now verifies controller registration against a test-only toolbar harness. _(Opened 2025-11-03 — Closed 2025-11-05)_
- Toolbar icons still regressed on GNUstep when using the DateTracker baseline (32 px art clipped). - Toolbar icons rendered as blank/garbled squares on GNUstep’s Sombre theme. Resolved on 2025-11-14 by generating new DALL·E assets, normalizing all PNGs to 8-bit RGBA, disabling the GNUstep dark-theme tint, and relaxing the bitmap visibility check so the toolbar always displays the intended pixels (active/inactive variants included). _(Opened 2025-11-03 — Closed 2025-11-14)_
- Custom cursor glyphs missing on GNUstep: switching tools always left the system arrow cursor. Resolved on 2025-11-19 by ensuring cursor assets ship inside the bundle, adding cursor asset/cursor rect probes, forcing the canvas to accept mouse-move events as first responder, and gating custom cursors on actual hover detection so GNUstep honors the tinted glyphs without ghosting over the toolbar. _(Opened 2025-11-17 — Closed 2025-11-19)_
- Text popover font combo stuck after the first drop-down on GNUstep: reopening the list logged `NSComboBoxCell` data-source warnings and left the combo unresponsive. Resolved on 2025-11-19 by routing every programmatic `setStringValue:` through a GNUstep-aware helper that defers updates while the field editor is active, flushing the pending value once editing ends, and adding `TextFontComboProbe` to enforce the behavior. `Tools/run_tests.sh` now passes with the new probe in the matrix. _(Opened 2025-11-19 — Closed 2025-11-19)_
- GNUstep text toolboxes painted opaque backgrounds and reverted to default font/color when reopening existing text. Resolved on 2025-11-20 by introducing a GNUstep-only transparent `NSTextView` subclass, hiding stored overlays during live edits, and reusing the saved font/color/size when editing so only the live text renders.
